# habitos semana 2 actividad 2

este es mi proyecto para la clase de programacion. 
se trata de una lista de habitos (estudio ajedrez) que se guardan en una base de datos.

## como hacerlo funcionar

### backend
1. entrar a la carpeta backend: cd backend
2. instalar todo: npm install
3. correr el servidor: node index.js
el servidor corre en el puerto 5000.

### frontend
1. abrir otra terminal y entrar a la carpeta frontend: cd frontend
2. instalar todo: npm install
3. correr el programa: npm run dev
la web se abre en el puerto 3000.

## cosas que use
- redux para el estado
- mongodb atlas para guardar los datos
- express para el servidor
- nextjs para la web
